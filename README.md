# DevOps Labs

Два практических проекта по Linux-администрированию и сетям. В каждом - пошаговый отчёт с командами, конфигами и скриншотами выполнения.

| Проект | Содержание | Отчёт |
|---|---|---|
| [ubuntu-admin](ubuntu-admin/) | Администрирование Ubuntu: сеть, SSH, systemd, диски, логи, cron | [report.md](ubuntu-admin/report.md) |
| [linux-network](linux-network/) | Маршрутизация, iptables/NAT, DHCP, SSH-туннели на стенде из 5 машин | [report.md](linux-network/report.md) |
