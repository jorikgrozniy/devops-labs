# ubuntu-admin - DO1_Linux

Администрирование Ubuntu: от установки до диагностики и планировщика заданий.

**Что сделано:**
- установка Ubuntu, создание пользователя и группы, выдача прав через sudo;
- hostname и timezone, получение адреса по DHCP, затем статическая сеть через netplan (IP, шлюз, DNS);
- обновление пакетов, синхронизация времени через systemd-timesyncd;
- SSH-сервер на порту 2022: настройка, автозапуск, проверка процессов и сокетов;
- мониторинг ресурсов (top/htop), анализ дисков (fdisk/df/du/ncdu);
- работа с журналами (dmesg/syslog/auth.log) и заданиями cron.

**Отчёт:** [report.md](report.md) - 15 разделов, 75 скриншотов.
